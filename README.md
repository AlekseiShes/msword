# Стиль библиографии по ГОСТ Р 7.0.100-2018

Настоящий стиль разработан на основе стиля [созданного Андреем Рогожниковым](https://github.com/irandom/docs/tree/master/gost-r-7.0.5-2008) (описания стиля [ГОСТ Р 7.0.5-2008](https://docs.cntd.ru/document/1200063713)) и приближен к стандарту [ГОСТ Р 7.0.100-2018](https://docs.cntd.ru/document/1200161674#7D20K3) и может использоваться в Microsoft Office Word для автоматической генерации библиографической ссылки (списка литературы). 

Настоящий стиль расчитан на штатный набор инструментов MS Word без установки дополнительных надстроек и программ.

Стиль для госта ГОСТ Р 7.0.100-2018 разработан автором Artem Mareev с применением программы Zotero: [Zotero-style-for-Gost-R-7.0.100-2018](https://github.com/ArtemMareev/Zotero-style-for-Gost-R-7.0.100-2018)
